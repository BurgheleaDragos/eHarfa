# eHarfa
Harfa electronica pentru cantari crestine


# Initializare

## Clonare

```
git clone https://github.com/BurgheleaDragos/eHarfa.Mobile.App.git
```

## Setup submodule

```
git submodule update --init --force --remote
```

## Actualizare submodule

```
git submodule foreach "git fetch && git checkout <branch-curent> && git pull"
```
